Advanced: fees, thresholds & collation

Whatnot's published schedule (Aug 2026): 8% commission on the hammer, plus 2.9% + 30¢ payment processing on the whole order (hammer + buyer S&H + tax). Buyers pay the S&H, which offsets your fulfillment cost — the desk nets both. Fulfillment is one number: everything it costs you to get an order out the door.

All cards count toward EV by default. Set a minimum to see only non-bulk value — every EV figure then shows what's excluded. Variant weight discounts showcase/borderless prints in pull-rate math.

Collation odds are editable estimates — WotC doesn't publish exact numbers. A play-booster line item marked "UB, no wildcard" uses the no-wildcard model.

Sealed prices come from tcgcsv.com (TCGplayer) through public CORS relays. For a permanent route, deploy this one-file Cloudflare Worker and paste its URL:

export default { async fetch(req) {
  const u = new URL(req.url);
  const r = await fetch("https://tcgcsv.com" + u.pathname + u.search);
  const res = new Response(r.body, r);
  res.headers.set("Access-Control-Allow-Origin", "*");
  return res;
}};
