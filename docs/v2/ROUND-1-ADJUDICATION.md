# ColorBreak V2 round-1 review adjudication

Date: 2026-08-13
Inputs: all seven requested perspectives in the three `reviews/round-1-*` documents
Evidence: primary-source dossier and sources linked by reviewers

## Decision standard

Feedback is accepted when it prevents false authority, makes a core job executable, or is supported by platform mechanics/economic invariants. It is deferred when the problem is real but needs unavailable demand, liquidity, identity, or platform data. It is dismissed when it asks ColorBreak to infer private utility, market demand, seller quality, or policy approval without evidence.

## Buyer decision contract

### Accepted

- **B1/B3/B4/B5/B7, GT-C1/GT-C2/GT-m2, EC-C1/EC-M2/EC-m1:** Replace `Bid/Conditional/Pass` and “max next bid” with a stable **modeled financial cap**, clearly a total Whatnot Max Bid/maximum hammer, plus optional manually entered **next available bid** and literal `under/at/over cap`. Current hammer never changes the cap. Unknown marginal costs can suppress the comparison.
- **B2/B6/B10, EC-M5:** Prepare/pre-bid becomes the preferred workflow. Live first viewport is cut to slot, cap, gap, all-in, one reason, evidence, and taken/undo. Test the entire one-phone Whatnot-like → ColorBreak → Whatnot-like task, wrong-spot errors, corrupted advice refusal, anchoring, and baseline comparison—not recall alone.
- **B8/B9, GT-C3, EC-C3/EC-m2:** Materiality is decision sensitivity: if plausible uncertainty changes the cap relationship, no cap is issued. Saved/shared plans carry product/rule revision, age, provenance, diff, and stale state. Seller assertions never preload buyer preferences.
- **GT-M1/GT-M2/GT-M3:** State the hybrid common/private-value boundary, never infer value from rival bids, model existing positions for repeat random purchases or explicitly refuse, and enforce buyer/seller private-variable noninterference.
- **EC-C4/EC-M1:** Replace scalar realization with documented modes. Release A defaults to modeled collection-market value and a conservative, banded net-resale sensitivity; personal utility is separate. Risk summaries follow the selected rule and include loss frequency/severity where applicable.

### Dismissed

- A universal “good bid” verdict, designer-authored mean/median blend, generic Chase-upside cap, automatic competitive/collector premium, and any cap that rises because rivals or sellers signal a higher price.
- Claiming the number is an objectively correct valuation. It is a modeled cap under a named rule and incomplete cost/utility scope.

### Deferred

- Numeric winner's-curse discount, card-level liquidity prediction, arbitrary utility functions, direct platform state, formal demand response, and precise cap deployment if the anchoring study fails.

## Competitive-player and collector value

### Accepted

- **P1–P5/P7/P8, C1–C5/C8/C9:** Add an optional, narrow wanted-card mode: canonical exact printing or acceptable-printing group, useful copy limit, user-authored value, probability of fulfilling target, duplicates at market-only value, and buy-the-single comparison where data permits. Routing is seller house rule, not color identity. Exact identity includes set, collector number, finish/treatment, language assumption, promo/stamp/serialized attributes, and source slot. Missing price never displays as buyer-facing $0.
- Seller graphics must keep mandatory denominator, probability, product, timestamp, typical/downside context, seller-featured label, and a complete linked list. Buyer analysis independently refreshes/diffs.

### Dismissed

- **P6/C6:** Automatic playability, metagame, format, collector-completion, condition-quality, or treatment premiums. Generic Chase upside is removed.

### Deferred

- Deck/collection imports, inventory synergies, event readiness, account integration, and delivered-condition scoring.
- **C7:** Chase Map is removed from the V2 testable scope. The V1 bug fix stays. It returns only after ranked exact-printing evidence is proven insufficient in a defined experiment.

## Seller economics and operations

### Accepted

- **S-C1/S-M3, GT-C4, EC-C2/EC-M6:** Remove expected fill, Easiest to fill, highest-margin optimizer, and categorical Run based on demand. Default output is conditional: `Economics clear target`, `Economics miss target`, or `Missing sales assumptions`. Ship explicit what-if comparison, not automatic optimization.
- **S-C2/S-m1:** Replace scalar partial-fill profit with fill-delay/cancellation stress. Unequal-price plans identify exact unsold sets/revenue frontiers. Product remains sealed; seller/household never absorbs an unsold spot.
- **S-C3/A-C2/EC-M3:** Default to **modeled contribution profit** and `planned net at these prices`. Net profit is reserved for a complete cost profile. Fee profiles are regional/category-specific, versioned, dated, expiring, overrideable, and reconciled to actual receipts.
- **S-C4:** Show cash basis and decision/opportunity-cost basis. Categorical economics status requires the decision basis; otherwise output is cash-margin-only.
- **S-C5:** Replace “policy compliant/approved” with “checked against ColorBreak ruleset dated…”. Split deterministic blockers, seller attestations, and Needs Whatnot review.
- **S-M1:** Branch pricing into PYT BIN/offer, PYT auction, and random auction. Required hammer/start/ask are never called expected hammer.
- **S-M5:** Add feasibility sketch (no decision/export) and launch-ready plan (complete rules/costs).
- **S-M2/S-m3:** Specify exact TSV, TXT, JSON, and editable 1080×1920 PNG export contracts, safe zones, rights/source metadata, one-click copy/download, and cross-artifact revision consistency.
- **S-M4/GT-C3:** Shared plans are unverified, provenance-preserving, versioned, and diffable—not seller identity proof.
- **A-C1/A-M1/A-M2/A-M3/A-M4:** Add cloneable named plans, immutable revision IDs, JSON/TSV import/export, a read-only host run sheet, multi-break show cost allocation, paste/CSV actuals and reconciliation, and operator throughput/error gates. Direct API access remains out of scope.

### Dismissed

- Fill forecasts from card EV, policy approval labels, conversion claims for 9:16 assets, seller identity/reputation inference, and “More chase visibility” as an economic objective.

### Deferred

- Automated fill/clearing-price/promotion forecasts, Pareto optimizers, direct Whatnot API, and seller scoring until authorized data and out-of-sample validation exist.

## Visualization and presentation

### Accepted

- **EC-m3:** Domain bounds are measure-specific. Probability/gross value cannot be negative; seller profit and buyer net surplus can, with a visible zero line.
- Ranked, filterable, exact-printing lists and literal conclusions precede charts. Containers have functional reasons only; no nested panels, casino motion, or tiny explanatory microcopy.

### Deferred

- Chase Map and novel scatterplots. No V2 story may depend on them before a controlled incremental-value test.
