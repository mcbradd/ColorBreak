Privacy

ColorBreak requires no account. Calculations run in your browser. Buyer and seller drafts, including bids, shipping, costs, actuals, and scenarios, exist only for the current browser session. Older durable drafts are removed on first use with an in-app status message. “Clear local ColorBreak app data” clears only ColorBreak-controlled browser storage and app cache. Use browser controls for browser history, HTTP cache, and clipboard.

Sharing

A public buyer setup link is created only when you select Copy buyer break setup. It includes composition, assignment, remaining slots, and value-filter settings. It never includes bids, shipping, seller costs, actuals, or saved financial state. The query is public and host/CDN-visible on its first load, before the app copies it into session working state and removes it from the address bar. Seller plans are private and are never shared. The service worker does not cache navigation or query-bearing share URLs.

Optional product analytics

If an analytics endpoint is configured, ColorBreak sends only allow-listed anonymous funnel events: persona selected, builder opened, product selected, builder abandoned, calculation completed, decision eligibility, draft resumed, buyer setup copied, and commercial CTA viewed/clicked. Events contain only mode, viewport class, product count, eligibility/status, or a coarse duration bucket. They never include bids, costs, card names, search text, URLs, share contents, contact details, or persistent identifiers. Session replay and sensitive-field capture are not used.

Data requests and third parties

The default app uses system fonts and published price snapshots bundled with the app; it does not make Google Fonts or live Scryfall API requests while evaluating a break. Card images are not loaded automatically. If a future image is requested, its third-party host will be named first and it is not stored by the app cache. External affiliate and support links are optional and subject to their own notices.

External links

Card details may include a clearly disclosed affiliate link when configured. Following it is optional; affiliate presence never changes analysis or ranking. External services apply their own privacy policies.

Future accounts

Saved scenarios, synchronization, and billing will receive an updated privacy notice before they launch. The free analytical experience will remain available if a paid entitlement fails.
