Production readiness requirements

ColorBreak’s public demo is analysis-only. It does not authorize bids, transactions, launch decisions, accounts, payments, or data collection.

Evidence must be current and complete

A product needs verified contents, a complete price snapshot with a visible source and observation time, and an explicit review of material omissions. A stale or incomplete snapshot cannot become decision-ready merely by waiting.

Actual seller results need receipts

Seller results require actual acquisition cost, receipt-backed orders and fees, and actual postage and packing for each shipment. Plans, estimates, targets, and scenarios are not receipts.

The host must enforce the policy

A production candidate needs an authorized HTTPS host that returns an enforceable response Content-Security-Policy including frame-ancestors, plus the reviewed response protections and artifact verification. GitHub Pages is not that host for this demo.

The release repository includes a production-host verification gate for the shell, support pages, manifest, service worker, and a missing route. It is deliberately separate from the Pages demo release.

Privacy and access interest

No access-interest endpoint is available. Any future access request needs a product-owned, privacy-reviewed destination, stated retention policy, explicit consent, and a design that excludes financial and session data.
